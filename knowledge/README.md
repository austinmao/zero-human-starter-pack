# Knowledge

This folder is where your own notes, project summaries and exports go.

**Only put things here in your PRIVATE `my-agents` copy.** Never put your own knowledge into the public starter pack.

Suggested layout:

```
knowledge/
  <project-name>/
    summary.md        what the project is, in one page
    instructions.md   the standing instructions you gave the project
    files/            documents the project used
    decisions.md      choices you made and why
```

Use `prompts/03-knowledge-dump-chatgpt.md` or `prompts/03-knowledge-dump-claude.md` to create these files, and `prompts/04-push-dump-to-github.md` to save them.
