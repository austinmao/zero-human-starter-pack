# 06: List everything you want to move

Do this before you move anything. It gives you one list, and you decide which items matter.

Use **Claude in Chrome**. Log in to claude.ai and chatgpt.com yourself first, in the same browser. For client work, use a separate browser profile, because Claude takes screenshots of what is on screen.

```
I want a list of my AI projects, custom GPTs and skills. This is read only.

1. Open claude.ai/projects. List every project name. Do not open any chat.
2. Open claude.ai/customize/skills. List the names of my own custom skills. Ignore Anthropic's built-in ones.
3. Open chatgpt.com. List every project name. Then open Explore GPTs > My GPTs and list every GPT I made.

Rules:
- Do not click delete, edit, share, rename or download anything.
- If a page needs a login, stop and tell me. Do not try to log in.
- If a list is long, scroll until you have all of it, and tell me the total.

Give me one table with these columns:
Source (Claude or ChatGPT) | Name | Type (project, GPT or skill) | Tier

Leave Tier blank. I will fill it in.
```

## Then choose tiers

Put a number in the Tier column:

- **1**: I use it this month, or it holds work I cannot recreate. Move it properly.
- **2**: Nice to keep. The export is enough.
- **3**: Old. Leave it.

Aim for 10 to 15 tier 1 items. Save the table as `knowledge/INVENTORY.md` in your private `my-agents` repo.
