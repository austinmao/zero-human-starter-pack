# Orchestrator: skills

Skills are optional add-ons. Names below were checked in Anthropic's public repo, https://github.com/anthropics/knowledge-work-plugins, on 25 Nov 2026.

| Skill | Where | Why |
|---|---|---|
| `productivity/memory-management` | knowledge-work-plugins | Helps the bot remember your people, projects and shorthand. |
| `productivity/task-management` | knowledge-work-plugins | Lets the Orchestrator read the shared task list. |
| `operations/status-report` | knowledge-work-plugins | Turns the weekly check into a tidy report. |

If your platform cannot install a skill, skip it. The bot works without them.
