# Messaging: skills and tools

| Tool | Where | Why |
|---|---|---|
| `wacli` | https://github.com/openclaw/wacli (docs at https://wacli.sh) | Reads, searches and sends WhatsApp from a terminal. The Code bot installs it. |
| iMessage in the Grok Bot desktop app | Grok Bot desktop app on a Mac | Reads and sends iMessage. Turn it on in the app. |
| `humanizer` | https://github.com/blader/humanizer (MIT) | Removes the signs of AI writing from every draft. Run it before you show a draft. |
| `partner-built/slack/slack-messaging` | knowledge-work-plugins | Writes clear Slack messages. Drafts only. |
| `enterprise-search/search` | knowledge-work-plugins | Finds a past conversation across connected tools. |

Notes
- Names checked on 25 Nov 2026. `wacli` is a third-party tool, not made by WhatsApp or Meta.
- The Code bot installs and maintains every tool. The Messaging bot uses a tool only after the Code bot says it is installed and tested.
- Telegram, Slack and other apps: connect them in Grok Bot's connected apps. Drafts only until you say otherwise.
